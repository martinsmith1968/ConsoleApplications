# ConsoleApplications

Useful Console Applications in .NET

## Applications

- BackgroundTimer
- BannerText (Prints text banners, with alignment and header/rule options)
- Calendar (Renders a month or year calendar to the console, with an events table)
- FigLetText (Renders text as large FIGlet-style ASCII art, using built-in or external fonts)
- GUIDGenerator
- IniFileHandler (Reads or writes a key's value in an INI file)
- PauseN (Just because...)
- PrintFormat (Formats a .NET composite format string against supplied arguments)
- SpecialFolders (Lists Windows special folder names and their resolved paths)
- Disk Summary (Can use [`Breakdown Chart`](https://spectreconsole.net/widgets/breakdownchart) from Spectre
- Toaster (Windows toast-style popup notifications, stacked across instances, with dynamic text, gradient
  backgrounds and more - see [Toaster Todo](apps/Toaster/Todo-Toaster.md))
- TomlFileHandler (Reads or writes a key's value in a TOML file)
- VarList (Lists environment variables, with search/sort, output as a table or grid)
